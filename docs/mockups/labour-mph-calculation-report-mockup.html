Reference

How the report is calculated

Formula (same as MPH Analysis and MPH Loss Reasons)

Authorized MPH (earned) = Σ over posted production entries quantity_produced × MPH number (MPH number from MPH Master, per department + sub-department) + fixed daily MPH of the department (MPH Master, department row), counted once per day, only if anyone was deployed that day Used MPH (deployed) = Σ over Today's Deployment entries mph full day = 12, half day = 6, max 12 per worker per day Net MPH = Authorized − Used (negative = loss) Efficiency = Authorized ÷ Used × 100 Used MPH/unit = Used ÷ Output (vs standard = Authorized ÷ Output)

Shared helper: src/lib/mphLoss.ts (fetchMphDay already returns items and workers per department for one date). Figures agree with the other MPH pages to 0.1 MPH.

Who sees it
Same as MPH Analysis (labour module view). Read-only; nothing is saved from this page.

What is different from MPH Analysis

  1. Calculation shown, not just totals. MPH Analysis gives one line per department; this report shows each production item × MPH number and each deployed worker × 12 / 6 that make up those totals.
  2. One production date at a time (prev / next day), with a range view for the month and a drill into one department day by day.
  3. Printable A4 for the daily production meeting, with signatures.
  4. Links to Loss Reasons: each department in loss shows whether the Production Coordinator has explained it (not started / partly / fully) and opens the entry page.

  4. Sub-department subtotals: keep them (as mocked) or show items only?
  5. Excel export: needed? One sheet per department, or one flat sheet with department / item / worker rows?
  6. Range matrix: show Net MPH (as mocked), or Efficiency %?
