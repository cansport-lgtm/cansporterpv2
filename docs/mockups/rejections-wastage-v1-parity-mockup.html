What the script does

1. staging ← csv/rw_rejections, rw_leakages, rw_wastages 2. pre-check every department / material / reason / disposition / user id exists in live (abort if not) 3. masters upsert rw_reasons, rw_materials, rw_units, rw_dispositions by id; deactivate Test / TEST / UNIT 4. backup copy the 17 rows about to change → rw_merge_backup 5. upsert INSERT … ON CONFLICT (id) DO UPDATE WHEN excluded.updated_at > live.updated_at 6. post-check per-day count + md5(ids) = backup for every day ≤ 15 Sep 7. rollback supabase/rollbacks/…_rw_v1_merge_down.sql
