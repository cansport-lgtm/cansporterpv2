How it connects

Fuel trip flow

Super admin sets FACTOR (0.1000, effective 01 Oct) ─────────────┐ ▼ Salesman: date · vehicle · start/end odo · PETROL PRICE · 2 meter photos │ km = end − start rate/km = price × factor │ amount = km × rate/km ──► trip posted (snapshots price, factor, rate) │ ┌─────────────────────────────────────────┘ ▼ Print sheet: 2 vouchers / A4 (Accounts + Salesman copy) ▼ Sales Manager approves ──► Fuel Weekly Payouts (existing) ──► Paid

Salesman planner flow

Salesman writes plan as free text (one line = one bullet; plain line = day heading) ▼ Save draft ──► Submit ──► visible to Sales Manager / Super Admin ▼ Print (A4, one plan per page) · later: link each plan line to a Visit Report
